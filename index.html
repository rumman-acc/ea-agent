assisted onlyno autonomous commit

Reference architecture

Solution Design

Five layers from experience surfaces down to systems of record — Layer 0 intake, Layer 1 orchestration, Layer 2 LeanIX-native agents, Layer 3 integration, Layer 4 systems of record. A cross-cutting column carries identity, audit, telemetry, evaluation and guardrails through every layer.

Reference diagram for illustration — box placement mirrors the actual request path: intake surfaces hand off to the orchestration core, which calls the six LeanIX-native agents, which reach LeanIX and external systems through Layer 3, landing in the systems of record at Layer 4.
